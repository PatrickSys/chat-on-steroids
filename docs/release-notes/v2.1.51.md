## Private history-recovery repair

Automatic conversation-history Retry now requires pending work owned by the app: queued input, a running turn, or an owed Goal/Loop continuation. An idle chat waits until real work arrives.

Working chats respect the bridge's provider hold and keep their retry step and deadline across page reloads. A delayed permission cannot click Retry after navigation, Stop, or replacement of the page.

This is a private Windows build based on upstream main, versioned above upstream 2.1.50 so the automatic updater does not immediately replace the repair. It is not an upstream release.
